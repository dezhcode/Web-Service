کلید API و احراز هویت

کلید را مدیر سرویس به شما می‌دهد؛ ثبت‌نام خودکار وجود ندارد. کلید یک رشتهٔ تصادفی حدود ۴۳ کاراکتری است و مثل رمز عبور باید محرمانه بماند. بهتر است برای هر برنامه یا هر نفر کلید جدا بگیرید تا اگر یکی لو رفت، فقط همان عوض شود.

کلید را در هر درخواست به یکی از این سه روش بفرستید:

روشنمونهتوضیح
هدر AuthorizationAuthorization: Bearer KEYروش پیشنهادی
هدر X-API-KeyX-API-Key: KEYبرای ابزارهایی که Bearer ندارند
پارامتر آدرس?api_key=KEYفقط برای WebSocket مرورگر که نمی‌تواند هدر بفرستد؛ کلید در لاگ‌ها ثبت می‌شود

کلید را در متغیر محیطی نگه دارید، نه داخل کد:

export EASYSAZ_API_KEY="your-key"        # Linux / macOS
$env:EASYSAZ_API_KEY="your-key"         # Windows PowerShell
کلید را در جاوااسکریپتِ سمت کاربرِ سایت خودتان نگذارید؛ هر بازدیدکننده می‌تواند آن را ببیند. درخواست را از سرور خودتان بفرستید. همیشه از آدرس https استفاده کنید.

پاسخ استریم (SSE)

POST/api/chat/streamنیاز به کلید

ورودی دقیقاً مثل /api/chat است، اما جواب هم‌زمان با تولید شدن و به‌صورت Server-Sent Events می‌رسد. هر رویداد یک خط data: با یک JSON است و رویدادها با یک خط خالی جدا می‌شوند.

HTTP/1.1 200 OK
Content-Type: text/event-stream

data: {"type": "delta", "text": "سل"}

data: {"type": "delta", "text": "ام!"}

data: {"type": "done"}
typeمعنی
deltaیک تکه از متن در فیلد text؛ تکه‌ها را به ترتیب به هم بچسبانید.
doneجواب کامل شد.
errorخطا در میانهٔ کار؛ متن خطا در message است و جواب ناقص مانده.

خطاهایی که پیش از شروع جریان رخ می‌دهند (کلید، ورودی نادرست) با همان کدهای وضعیت معمولی و بدنهٔ JSON برمی‌گردند (خطاها).

import json
import os
import requests

BASE_URL = "{{BASE}}"
HEADERS = {"Authorization": f"Bearer {os.environ['EASYSAZ_API_KEY']}"}

def ask_stream(prompt):
    with requests.post(f"{BASE_URL}/api/chat/stream", headers=HEADERS,
                       json={"prompt": prompt}, stream=True, timeout=150) as r:
        if r.status_code != 200:
            raise RuntimeError(f"{r.status_code}: {r.text[:200]}")
        r.encoding = "utf-8"          # without this, Persian text gets garbled
        for line in r.iter_lines(decode_unicode=True):
            if not line.startswith("data:"):
                continue
            event = json.loads(line[5:])
            if event["type"] == "delta":
                yield event["text"]
            elif event["type"] == "error":
                raise RuntimeError(event["message"])
            elif event["type"] == "done":
                return

for piece in ask_stream("Count from 1 to 5"):
    print(piece, end="", flush=True)
print()
curl -N -X POST {{BASE}}/api/chat/stream \

// EventSource can't send POST or headers, so read the stream with fetch.
async function askStream(prompt, onText) {
  const r = await fetch("{{BASE}}/api/chat/stream", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.EASYSAZ_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ prompt }),
  });
  if (!r.ok) throw new Error(`${r.status}: ${await r.text()}`);

  const reader = r.body.getReader();
  const decoder = new TextDecoder();
  let buf = "";
  for (;;) {
    const { value, done } = await reader.read();
    if (done) return;
    buf += decoder.decode(value, { stream: true });
    let i;
    while ((i = buf.indexOf("\n\n")) >= 0) {
      const block = buf.slice(0, i);
      buf = buf.slice(i + 2);
      for (const line of block.split("\n")) {
        if (!line.startsWith("data:")) continue;
        const ev = JSON.parse(line.slice(5));
        if (ev.type === "delta") onText(ev.text);
        else if (ev.type === "error") throw new Error(ev.message);
        else if (ev.type === "done") return;
      }
    }
  }
}

await askStream("Count from 1 to 5", (t) => process.stdout.write(t));

WebSocket

WS/wsنیاز به کلیدفقط روی سرور ASGI

یک اتصال دائمی که در آن هر اتصال یک مکالمهٔ چندمرحله‌ای است: سرویس پیام‌های قبلی همان اتصال را به خاطر دارد. روی هاست اشتراکی (cPanel / Passenger) در دسترس نیست؛ آنجا از استریم SSE استفاده کنید. درخواست HTTP معمولی به /ws کد ۴۲۶ و پیام راهنما برمی‌گرداند.

جهتپیامتوضیح
کلاینت ← سرور{"type":"chat","id":"1","prompt":"..."}سؤال؛ image_url یا image_base64 هم پذیرفته می‌شود. id دلخواه است و در پاسخ‌ها برمی‌گردد.
کلاینت ← سرور{"type":"reset"}شروع مکالمهٔ تازه روی همان اتصال
کلاینت ← سرور{"type":"ping"}بررسی زنده بودن اتصال
سرور ← کلاینت{"type":"ready","mode":"smart"}اتصال آماده است (اولین پیام)
سرور ← کلاینت{"type":"delta","id":"1","text":"..."}تکه‌ای از جواب (تکرار می‌شود)
سرور ← کلاینت{"type":"done","id":"1","text":"..."}جواب کامل
سرور ← کلاینت{"type":"error","id":"1","message":"..."}خطا؛ اتصال باز می‌ماند
سرور ← کلاینت{"type":"reset"} / {"type":"pong"}تأیید reset و ping

با کلید نادرست، اتصال با کد 1008 بسته می‌شود.

const ws = new WebSocket("{{WSBASE}}/ws?api_key=" + encodeURIComponent(KEY));
ws.onmessage = (e) => {
  const m = JSON.parse(e.data);
  if (m.type === "ready") ws.send(JSON.stringify({ type: "chat", id: "1", prompt: "سلام" }));
  else if (m.type === "delta") console.log(m.text);
  else if (m.type === "done") console.log("full reply:", m.text);

import asyncio, json, os
import websockets

async def main():
    headers = {"Authorization": f"Bearer {os.environ['EASYSAZ_API_KEY']}"}
    async with websockets.connect("{{WSBASE}}/ws", additional_headers=headers) as ws:
        await ws.recv()                                   # {"type": "ready"}
        for question in ["My name is Sara.", "What is my name?"]:
            await ws.send(json.dumps({"type": "chat", "prompt": question}))
            while True:
                m = json.loads(await ws.recv())
                if m["type"] == "delta":
                    print(m["text"], end="", flush=True)
                elif m["type"] in ("done", "error"):
                    print(); break

asyncio.run(main())

مکالمهٔ چندمرحله‌ای

در /api/chat و /api/chat/stream هر درخواست یک مکالمهٔ تازه است و سرویس سؤال‌های قبلی را نمی‌داند. اگر سؤال بعدی به قبلی وابسته است، متن قبلی را خودتان در prompt بگنجانید (یا از WebSocket استفاده کنید):

history = []

def chat(user_text):
    history.append(f"User: {user_text}")
    prompt = "\n".join(history) + "\nAssistant:"
    answer = ask(prompt)                      # ask() from the /api/chat example
    history.append(f"Assistant: {answer}")
    return answer

chat("My name is Sara.")
print(chat("What is my name?"))

وقتی تاریخچه طولانی شود به سقف ۸۰۰۰ کاراکتر می‌رسد؛ قدیمی‌ترین پیام‌ها را از history حذف کنید.

خطاها و کدهای وضعیت

پاسخ موفق همیشه کد ۲۰۰ است. هر خطای دیگر بدنه‌ای به شکل {"error": "..."} دارد.

کدمعنیچه کنید
400ورودی نادرست: prompt خالی یا خیلی بلند، JSON خراب، تصویر بزرگ، لینک تصویر نامعتبر یا داخلیمتن error می‌گوید کجا اشکال دارد؛ ورودی را اصلاح کنید
401کلید نفرستاده‌اید یا نادرست استکلید را با مدیر سرویس چک کنید
404مسیر اشتباه استآدرس پایه و مسیر را چک کنید
405متد اشتباه (مثلاً GET به جای POST)مسیرهای چت فقط POST می‌پذیرند
426درخواست HTTP معمولی به /wsبا کلاینت WebSocket وصل شوید یا از SSE استفاده کنید
502ارتباط با موتور هوش مصنوعی ناموفق بود (upstream request failed)چند ثانیه بعد دوباره بفرستید
503سرویس هنوز کلیدی تنظیم نکرده استبه مدیر سرویس خبر دهید
504 / 524پراکسی میان‌راه پیش از پایان جواب اتصال را قطع کردسؤال را کوتاه‌تر کنید یا از استریم استفاده کنید

فقط خطای ۵۰۲ با تکرار درست می‌شود:

import time

def ask_with_retry(prompt, tries=3):
    for i in range(tries):
        try:
            return ask(prompt)
        except RuntimeError as e:
            if not str(e).startswith("502") or i == tries - 1:
                raise
            time.sleep(2 * (i + 1))

برای مدیر سرویس: صدور کلید

کلیدها در متغیر API_KEY سرور نگه داشته می‌شوند و چند کلید با کاما جدا می‌شوند. به هر کاربر یا برنامه یک کلید جدا بدهید.

  1. کلید بسازید: python -c "import secrets; print(secrets.token_urlsafe(32))"
  2. در فایل .env کنار برنامه، کلید را با کاما به خط API_KEY اضافه کنید: API_KEY=old-key,new-user-key
  3. برنامه را Restart کنید (در Setup Python App دکمهٔ Restart، یا touch tmp/restart.txt).
  4. برای لغو دسترسی، کلید را از همان خط حذف و دوباره Restart کنید.

اگر API_KEY را در Environment variables صفحهٔ Setup Python App هم گذاشته‌اید، آن مقدار اولویت دارد و تغییر .env اثری ندارد.
